DBMS stands for Database Management System.

It is software used to:
- create databases
- store data
- retrieve data efficiently
- update and delete data
- manage users, security, and permissions
- maintain data consistency and reliability

Examples of DBMS:
- MySQL
- PostgreSQL
- Oracle
- Microsoft SQL Server
- MongoDB

Simple difference:
- Database = the organized collection of data
- DBMS = the system/program that manages that database

In short, a DBMS helps you work with data in a structured and efficient way using tools like SQL.
