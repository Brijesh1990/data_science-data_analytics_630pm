**MySQL** is a relational database management system (RDBMS). It stores data in tables made of rows and columns, and lets applications retrieve, add, update, and delete data using **SQL** (Structured Query Language).

For example, a shop might use MySQL to store products, customers, and orders in related tables. MySQL is widely used for websites and business applications.

**In short:** SQL is the language used to work with databases; MySQL is software that manages one.
