# 🌐 Types of Websites

A **website** is a collection of web pages and digital content available on the internet through a domain name or web address.

Websites can be classified based on their **purpose, audience, functionality, business model, and technology**.

# 1. Basic Website Categories

## 1.1 Static Website

A static website contains mostly fixed HTML content.

### Technologies

* HTML
* CSS
* JavaScript
* Bootstrap
* Tailwind CSS

### Examples

* Company profile
* Portfolio
* Landing page
* Documentation

---

## 1.2 Dynamic Website

A dynamic website generates content based on user requests, databases, authentication, or other backend logic.

### Technologies

* PHP
* Laravel
* Node.js
* Express.js
* Python
* Django
* ASP.NET
* MySQL
* MongoDB

### Examples

* E-commerce
* CRM
* HRMS
* ERP
* Student management system

---

## 1.3 Single Page Application

An SPA loads a main application and dynamically changes the content without fully reloading the page.

### Technologies

* React
* Angular
* Vue
* Svelte

### Examples

* Admin dashboard
* Banking application
* Project management application
* CRM

# 🏗️ Common Website Architecture

A modern website can contain several layers:

```text
                    WEBSITE
                       │
          ┌────────────┴────────────┐
          │                         │
       FRONTEND                  BACKEND
          │                         │
   ┌──────┼──────┐           ┌──────┼──────┐
   │      │      │           │      │      │
 HTML    CSS     JS         API   Auth   Logic
   │      │      │           │
   └──────┴──────┘           │
                             ↓
                          DATABASE
                             │
                  ┌──────────┼──────────┐
                  │          │          │
                MySQL     MongoDB   PostgreSQL
```
